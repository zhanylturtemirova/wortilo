# Проверка первого экрана — 9 октября 2026

## Подтверждено

- `npm run typecheck`: успешно.
- `npm run lint`: успешно. Первый запуск Expo установил линтер, но его процесс не смог сразу разрешить новый пакет; повторный запуск прошёл.
- `npx expo export --platform ios --platform android --output-dir /tmp/wortilo-native-export`: JavaScript/Hermes bundles собраны для обеих платформ. Это не IPA/APK и не запуск на устройстве.
- Браузер, ручная проверка: ввод текста, изменение исходного языка, удаление исходного Russian с переключением на German, блокировка удаления при двух языках, возврат Russian с прежним текстом, закрытие выбора, отключённое сохранение.
- Веб-экран осмотрен при ширине 390 CSS px: поля и кнопки помещаются, страница прокручивается.

## Ещё не подтверждено

Нативный запуск iOS/Android, экранная клавиатура, VoiceOver/TalkBack, увеличенный системный шрифт и тёмная тема визуально. Попытка чтения списка iOS Simulator в изолированном окружении не получила доступа к CoreSimulatorService; это не ошибка приложения.

## Зависимости

`npm audit` сообщил 22 предупреждения: 15 high, 7 moderate, включая транзитивные цепочки Expo/Metro и React Native. Среди исходных advisory: braces, node-forge, uuid. Это не 22 независимые ошибки кода экрана. Наличие предупреждений не доказывает эксплуатацию в приложении, но требует отдельного анализа перед релизом.

Предложенный `npm audit fix --force` меняет Expo на 44.0.6 и React Native на 0.72.17; не применён из-за несовместимости с SDK 57. Не считать зависимости проверенными для production. Платных сервисов и публикации нет.
