# Первый экран Wortilo: учебный шаг 1

Задача этого шага — освоить экран React Native: ввод, props, state, Flexbox и безопасные отступы телефона. Это ещё не работающий переводчик. Нет сети, backend, авторизации и расходов на API. Кнопка сохранения отключена; введённое не записывается на диск. Нижнее меню, история и озвучивание появятся вместе с соответствующими функциями.

## Как запустить

Из папки `wortilo/mobile`:

```sh
npm install
npm start
```

Expo запускает Metro — сервер, который собирает JavaScript и отдаёт его приложению. Терминал покажет адрес и QR-код. Expo Go должен поддерживать SDK проекта (сейчас 57). На телефоне открой этот адрес через Expo Go, используя доступную с телефона сеть. Не сканируй QR-код браузером как обычный сайт.

- `npm run ios`: запуск через установленный iOS Simulator/Xcode.
- `npm run android`: запуск через доступный Android Emulator; сначала создай и запусти устройство в Android Studio → Device Manager.
- `npm run web`: браузерный просмотр того же экрана.
- `npm run typecheck`: проверка типов без сборки.
- `npm run lint`: проверка правил кода.

Expo Go — оболочка для разработки. На этом шаге не нужны публикация в магазинах, Apple Developer membership или платные сборки. Виджеты и другие дополнительные нативные возможности позже потребуют отдельной development build.

## Порядок чтения кода

1. `index.ts` регистрирует приложение средствами Expo.
2. `App.tsx` добавляет SafeAreaProvider и показывает TranslatorScreen. Provider сообщает дочерним компонентам отступы вокруг выреза экрана и системных областей.
3. `src/screens/TranslatorScreen.tsx` хранит четыре состояния: порядок языков, исходный язык, тексты и видимость выбора языков.
4. `src/components/LanguagePanel.tsx` получает данные через props и отображает один языковой блок. В нём нет собственной копии текста.
5. `src/theme.ts` содержит цвета. `useColorScheme()` выбирает палитру по системной теме. Это не локализация: строки пока английские.

## Проследи один ввод

Когда печатаешь в German, `TextInput` вызывает `onChangeText`. LanguagePanel передаёт текст экрану. `changeText('de', value)` меняет `source` и `texts`. React снова вызывает компоненты с новыми props. German получает новую строку и выделение исходного блока. Остальные поля не переводятся автоматически — провайдер перевода ещё не подключён.

`setTexts(previous => ({ ...previous, [code]: value }))` создаёт новый объект, копирует другие языки и меняет только выбранный ключ. Функциональный setter берёт актуальное предыдущее состояние. `key={code}` сохраняет идентичность блока при изменении списка.

## Чем отличается от React в браузере

| Web | React Native |
| --- | --- |
| div | View |
| текст внутри элемента | Text |
| textarea | TextInput с multiline |
| button | Pressable с accessibilityRole |
| CSS | StyleSheet и объекты стилей |
| overflow: scroll | ScrollView |

Нет фиксированных координат из Figma: блоки идут вертикально и растут с содержимым. KeyboardAvoidingView помогает разместить содержимое при открытой клавиатуре; реальное поведение нужно проверить на обеих ОС. Навигации пока нет; когда появится вторая страница, проектные правила требуют Expo Router.

## Что проверить руками

1. Введи `der Alltag`, `everyday life`, `повседневная жизнь` в соответствующие поля. Последнее изменённое поле становится источником.
2. Нажми Add / remove languages. Удали Russian: останутся два блока. Удаление остальных станет недоступным.
3. Добавь Russian: его текст должен вернуться. Если скрыть исходный язык, источником станет первый оставшийся.
4. Закрой и снова открой выбор: состав блоков не меняется. Перезапуск приложения сбросит всё — постоянного хранения пока нет.
5. Введи длинный текст, прокрути страницу с клавиатурой, увеличь системный шрифт, поверни устройство. Проверь, что можно добраться до всех полей.
6. Переключи системную светлую/тёмную тему. Проверь читаемость placeholder и текста.
7. Кнопка Save to flashcards должна оставаться недоступной и не сообщать об успешной записи.

## Небольшое упражнение

Самостоятельно добавь под исходным полем счётчик введённых слов. Сначала реши: нужна ли для него ещё одна переменная state, если число можно вычислить из `value`? Проверь пустой текст, несколько пробелов и переносы строк. Следующий шаг вместе — ревью этого изменения, затем выбор и подключение перевода.
